# benchpress-legal

「练了吗健身」的公开支持页与隐私政策页，供 App Store Connect 使用。

- 支持：https://g1998815.github.io/benchpress-legal/
- 隐私政策：https://g1998815.github.io/benchpress-legal/privacy.html

## 更新

直接改仓库根目录的 `index.html` / `privacy.html` / `style.css` 即可。

发布前请把页面中的 `[请填写联系邮箱]` 和 `[请填写开发者名称]` 替换成真实信息。

## 部署

GitHub 仓库 → Settings → Pages → Source 选 `Deploy from a branch`，
分支 `main`、目录 `/ (root)`。
